# Physical field option search

### D-109 — Explicit options from exact registered field populations

Accepted continuation of D-103 and D-106–D-108, 2026-10-09. The same native option
service supports safe physical text, UUID, integer, numeric and boolean selectors
in dataset authoring and saved private/published report filters. A catalog column
ID resolves against an exact registered source/context/dataset/revision/schema
pin. Reviewed topic origins retain their actual publication/rule checks; raw
origins invent no topic. No name-based semantics, joins, client SQL or implicit
analysis are introduced. Dates/timestamps retain explicit range controls.

Text uses bounded escaped substring search; other types use exact bound values.
Empty search browses the full authorized field population, excluding NULL and
without silently applying other chart defaults. Native ordering and typed cursor
parameters preserve numeric order. Exact strings carry all physical values into
the browser. Explicit Search/Next alone starts source work; Done/Cancel only
changes local selections. The existing validated read, custody, budget, source,
report and current authority fences remain mandatory. Uncertain responses retain
original lookup recovery and cannot automatically replay a source query.

Migration 090 adds exclusive physical coordinates to protected option custody
without rewriting old request/record bytes or weakening the native read journal.
Topic foreign keys remain for actual topics. Pengui derives and checks each
actual dependency before minting; an exact raw dataset cannot widen to other
sources, contexts, datasets or topics. These changes add no identity store.

Private predecessor behavior informed the separation of field selection, typed
saved defaults, explicit option discovery and temporary report inputs. No private
code or schemas are copied. Native, synthetic browser and actual signed-in host
qualification are distinct; the active flexible-authoring goal owns the latter
and the independent people/Team audience controls.
