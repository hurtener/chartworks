# Scalar predicate entailment continuation

### D-094 — Exact equality required by every selected scalar occurrence

Status: implemented for local qualification

A new characterization demonstrated a concrete missing request: an explicit
reviewed paid-order selection is refused even though all selected scalar
SUM/COUNT leaves already require that exact predicate, including reviewed
complete-key parent filters. This is fresh work, not recovered version history.

Adopt `analytical-metrics-v13` and binding schema6 only for canonical text
equality with NULL exclusion under the already qualified PostgreSQL scoped
singleton shape. Every selected root and expression occurrence has an independent
witness, including repeated measures and inherited same-fact KPI contexts.
Immutable publication/route reconstruction establishes semantic identity;
execution separately checks exact compiled predicates, admitted physical INNER
edges, complete keys and current uniqueness. An unproved occurrence or request
constraint refuses the entire extension before generation.

The binder retains ordinary v9 period SQL and parameters byte-for-byte. It adds
explicit zero-parameter entailment effects; it does not remove metric predicates,
guess cross-fact placement or infer from names. SUM/COUNT empty/all-NULL semantics
and output ordinals remain unchanged. Public evidence is value-free; replay
reconstructs complete protected evidence and current authority before native proof
or retained-result reuse. Old versions retain their meaning and reject new fields.
Migration 081 appends the coupled v13/schema6 storage shape without rewriting old
rows. Automatic learning and owned-example consumption remain ineligible.

The [closed contract](../contracts/analytical-scalar-entailment-v1.md) defines the
limits and mandatory tests. Finite sets, singleton IN, ranges, arbitrary Boolean
inference, outer joins, grouped domains and other engines remain unqualified.
Recorded model fixtures, focused tests and local checks do not establish live
provider quality, hosted CI or broader recovery/release completion.
