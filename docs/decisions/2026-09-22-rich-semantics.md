# D-075 — Rich semantic values are reviewed artifacts and selected metrics are atomic dependency closures

Status: accepted for CW-04, 2026-09-22.

Chartworks represents business aliases, semantic roles, governed non-sensitive
value mappings, temporal calendars/grains, units, filter concepts and reviewed
relationship evidence in the one versioned topic-pack model. It does not restore
unrestricted raw profile samples. Governed values require explicit non-sensitive
column review plus bounded evidence/policy provenance.

When a measure or KPI is selected for generation, routing resolves its complete
transitive semantic dependency closure from the exact authorized publication. The
single tokenizer owner admits that closure as one mandatory group or returns typed
insufficiency before provider work. A metric label can never survive while its
formula, input measures, columns, relevant dimensions/values/time policy, filters or
required joins are independently dropped.

Candidate and rejected relationships remain inspectable authoring evidence and are
never queryable joins. Confirmed joins remain same-source/context/revision and are
the only relationship form consumed by routing and validation. Model enhancement
may enrich bounded column semantics but cannot publish meaning, create authority or
reintroduce sample rows.

Why: privacy-safe value awareness and rich business meaning are necessary for query
quality, while immutable review, exact provenance and atomic context admission keep
that richness from weakening authority or execution safety.
