# Visual chart and private-page authoring

### D-097 — Canvas-first manual authoring with governed mutations

Accepted owner continuation, 2026-10-03. Extends D-096 beyond the initial
published-output selection checkpoint. This is requested scope, not a claim that
all controls, backend operations or host integration have shipped.

## Required experience

One application serves MCP Apps and the registered embedded host. Builder is a
canvas-first editor: a large twelve-column grid, direct snapped move/resize,
contextual component catalog and inspector, real chart-type/field controls and
independent pages. Consumer presents the same saved composition without editing
chrome. Preserve unrelated custom geometry. Pointer cancellation, keyboard
alternatives, dirty-state recovery and CAS conflicts are correctness requirements.

The catalog distinguishes existing approved outputs from creating a visualization.
Only actual domain/renderer kinds may be offered; never relabel another chart.
Combo remains unavailable until a genuine closed mapping and renderer exists.
Empty data, invalid bindings, partial failures and stale previews stay explicit.

## Authority and lifecycle

Pengui remains the only identity, grant, audience and issuer owner. Every action
uses native scopes and exact resource/context reach. No role/profile or UI mode
grants authority. Report presentation cannot replace chart mappings or semantics.
Default report-local chart edits create an explicitly authorized private block
copy, never silently change a shared publication. Source read plus explicit source
preview eligibility is required even for a published source; ordinary read cannot
transfer hidden SQL into an editable target. The purpose-specific internal copy
seam does not execute a preview or return SQL. New-target/tenant/topic/dependency
write and chart-binding authority remain independent. A dedicated future central
copy grant needs an explicit contract decision, not implicit scope widening.

A mapping amendment receives one selected output, immutable revision/digest and
CAS version. The server preserves SQL, source, semantic/rule/template pins,
parameters, policies and untargeted outputs. Schema-only binding is not actual
data validation; validation is a separate explicit bounded source read. Old
validation, certification and publication evidence never transfers to a copy.
Unknown outcomes are inspected and remain fenced, never blindly replayed.

Publication can expand actor-private visibility to an already authorized central
audience even without creating a grant. It cannot be renamed as private approval.
A narrow private composition bridge reuses the validated private_preview lane,
with exact revision/digest, original actor, current document/block preview and
execution authority, dependencies and unexpired matching validation. This is
checked at admission and unfinished execution checkpoints. Retained private
results remain private. Report review/publication rejects unresolved private
references, even after a source block is later published, until explicit rebind.

## Real pages and dataset-first creation

Version-three inline report_pages have stable page IDs, report-global widget IDs
and independent widgets, filters/defaults and presentation. One report owns their
CAS/review/publication and authority. Aggregate budgets apply across pages. Version
two is not silently rewritten or redigested. Schedules, nested dashboards and
retained views must preserve every page or explicitly reject unsupported input.
No hidden child reports or page-grant grammar is introduced.

Dataset-first creation requires closed logical intent over reviewed dimensions
and measures. The server resolves identifiers and uses the existing validator,
executor and attempt journal. An explicit bounded preparation observes actual
schema; the browser cannot supply SQL, result rows or guessed aggregate types.
Initial qualification may be PostgreSQL-only. Unsupported rules, filtered
populations, completeness or calendar policies reject rather than disappear.
Preparation custody is actor/session/target/digest-bound and rechecked before
consumption. Retrying an operation must not duplicate its physical query. Unknown
attempt liabilities cannot be discarded on expiry. No model repair path is used.

## Incremental evidence

Direct-grid, mapping, private pages and deterministic creation are separate
checkpoints; none alone closes the complete requested Builder. Existing viewer
contracts, shared rendering and execution/renderer budgets remain unchanged.
Require real storage/authority/CAS/revocation/expiry tests and HTTP/MCP/SDK parity.
Browser proof in both adapters must exercise empty canvas, palette and real type
selection, populated charts, drag/resize/cancel, exact save/reopen, page isolation,
staged edit cancellation, private preview and clean Consumer. Inspect actual
screenshots before visual qualification. A synthetic host is not real Pengui
launch/admission. No production deployment, credentials or live provider calls
are authorized by this decision.
