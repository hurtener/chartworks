# Registered-source catalog and picker checkpoint

The Builder now browses registered sources and their datasets without a topic.
Each selected table carries current source, context, revision and schema digest
into the shared typed field compiler. Physical fields and aggregates remain
explicit; there is no name-based analysis, inferred metric or automatic join.
Private predecessor research informed the schema-driven selection pattern only.

Pengui composes both HTTP and no-chat MCP catalogs using exact current grants,
eight native metadata reads per page and a final session/policy fence. Empty
pages preserve continuation. Chartworks adds a source-page public operation;
source filtering and cursor ordering happen before LIMIT. Existing source list,
dataset metadata and topic authoring remain compatible. This adds no migration.

Single-agent adversarial review covered cross-tenant selection, partial scope,
changed schema/context pins, sparse pagination, request injection, native failures,
revocation during reads, late responses, pending-operation custody and UI cleanup.
It found catalog metadata surviving suspension, a silent topic-catalog ceiling,
and the mobile empty-canvas clipping. These are corrected with focused checks.
No independent reviewer or subagent was used.

Local tests include actual PostgreSQL source pagination, all catalog transport
surfaces, registry parity, Pengui policy race cases, both frontend host adapters,
typed/source picker contracts and Chromium on both compiled resource variants.
The captures are synthetic host fixtures. They are not a signed-in product or
live provider qualification. The final goal walkthrough is still outstanding.

A broader Phase23/AC01 query parity run failed on `analytical_mismatch`, whose
actual error was absent from the NLQ registration. Catalog operations preceding
that failure passed, and dedicated catalog-surface acceptance isolates that seam.
The query failure remains an open goal qualification finding. An old fixed MCP
inventory count also failed; discovery now compares names to the actual permitted
registrations and explicitly requires the source-page operation.

Physical-field filters, uploaded-data host acceptance and independent report
access management remain unfinished. Hosted CI is billing-blocked; PRs stay draft
and unmerged. There is no deployment or whole-product release claim.

Final local checkpoint evidence: both compiled Chromium transports pass 387
assertions each, with desktop/mobile source picker captures; Pengui frontend
checks pass 88 cases and Svelte reports zero errors/warnings. Native source
pagination/surface and phase 22/23 catalog inventory groups pass. Source,
source API, SDK and focused native catalog race checks pass. The initial macOS
planning harness compared a canonical `/private/var` path with its `/var` alias;
using a canonical task temporary directory passes without changing the tests.
Generated assets, mirrored rule files and diff checks pass.
